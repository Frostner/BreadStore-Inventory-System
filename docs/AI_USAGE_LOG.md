## Reflection questions

**What did AI help me accomplish?** Write only the tasks where AI actually assisted you.

**What did I personally verify?** List specific commands, screenshots, table records, SQL queries and manual interactions **that you personally ran**.

**What did I learn?** Explain a database relationship, transaction, validation rule or security practice in your own words.

**What limitations or errors did I discover?** Document real limitations you verified. For example, distinguish rule-based restock estimates from an ML/AI model; don't mislabel the system as AI-assisted if no ML is present.

**Reminder:** The screenshot and automated run performed during project generation are starting evidence, not proof that you performed your own tests. Add dated personal verification before handing this in.
